Optional provider-specific fast path for writing a large batch of audit rows, bypassing EF Core's per-entity tracked-entity insert. Register an implementation in DI as IAuditBulkWriter (e.g. services.AddSingleton<IAuditBulkWriter, TWriter>()) — UseAuditing and AuditingDbContext's constructor both resolve it via serviceProvider.GetService<IAuditBulkWriter>() at registration time and pass it through as an ordinary constructor parameter. Consulted only when BulkInsertRowThreshold is set and the pending header count meets or exceeds it; the standard EF Core insert path is used otherwise, including whenever no writer is registered.
